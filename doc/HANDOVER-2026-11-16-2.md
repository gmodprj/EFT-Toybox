## 1. 무엇을 만들었나 — ModCardKorean

웹 화면 글귀는 세 군데에서 온다. 각각 다른 길로 잡았다.

| 글귀 | 어디서 오나 | 어떻게 바꾸나 |
| --- | --- | --- |
| 첫 화면 모드 카드 | 각 모드 DLL 안의 리터럴(`ModPage`) | `OnLoadAsync` 에서 싱글턴을 제자리 수정 — `mod-cards.ko.json` |
| 모드 페이지 안쪽 | 모드 Blazor 컴포넌트·독립 HTML | `IStartupFilter` 가 HTML 마다 `ko-ui.js` 를 끼우고 MutationObserver 로 사전·규칙 적용 |
| 아이템 이름 | 서버 메모리의 게임 locale | `/modcardkorean/item-names.json` 이 그 자리에서 en→kr 을 뽑는다 |

소스는 [src/ModCardKorean](../src/ModCardKorean)·[src/ServerWebUiKorean](../src/ServerWebUiKorean), 설치는
`tools/install-modcardkorean.ps1`. **SPT 파일은 하나도 건드리지 않는다.** `ko-ui.js`·`ko-ui.json` 은 디스크에서
그때그때 읽으므로 **서버를 끄지 않고 복사만 해도** 새로고침으로 반영된다(DLL·`mod-cards.ko.json` 은 재기동).

사전 고칠 때는 `src/ServerWebUiKorean/patches/NN-*.json` 을 쓰고 `node tools/merge-web-ui-dict.mjs <패치>` 로 합친다
(기존 값을 다르게 덮으면 알려 준다). 패치는 01~14 까지 있다.

## 3. QuestCodex 아이템 이름 — 웹이 아니라 게임 locale 에 넣었다

웹에 남은 아이템 이름은 **kr 로케일에도 영문**인 것이라 웹 사전에 넣으면 게임과 어긋난다. 그래서
`SptKoreanLocale` 에 넣었다.

| 사전 | 열쇠 | 내용 |
| --- | --- | --- |
| `item-names-questcodex-1.json` | Name 174 + ShortName 95, keptAsIs 1 | 처음 점검에서 남은 202건 중 열쇠가 있는 175 |
| `item-names-questcodex-2.json` | Name 47 + ShortName 20, keptAsIs 2 | 번역기를 고치자 드러난 50건(1 과 겹치는 1 제외) |

표기 규칙(다음 묶음도 이대로):
- 공식 kr 결 — **브랜드·모델명·위장 무늬는 영문, 물건 종류만 한국어**(플레이트 캐리어·방탄복·방탄판·체스트 리그·배낭).
- 탄창은 `30발, … 탄창`, 총열은 `… 총열`, raid backpack=급습 배낭, assault backpack=돌격 배낭.
- 고유 낱말은 퀘스트 목표 사전(`lang-src/quest-objectives.json`)에 맞춘다 — 등대지기·프라퍼·레프·스키어·크노소스·래버린스·테라그룹, USEC Intelligence Support Bureau = USEC 정보지원국.
- **방탄판·탄약 상자의 `(3/50)` 꼬리는 값에 함께 적는다** — 앞선 변환기가 locale 값에 써 넣은 것이라 빼면 사라진다.
- **색 태그와 ●○ 는 넣지 않는다** — 내려줄 때 덧대는 꾸밈이다.
- `coveragePatterns` 는 그 id 로 좁힌다 — 넓게 적으면 손대지 않은 수천 개가 "빠뜨림"으로 잡힌다.
- 모드가 이름을 바꿔 공식 한국어가 덮인 것(Red Bull·Osprey 9 2.0)은 공식 낱말을 되쓴다.

## 4. 번역기 회귀 하나

한 요소 안에 글자 조각이 둘 이상이고 통째로 사전에 없으면 원문으로 두게 했었다(낱개로 바꾸면 어순이 뒤집힌다).
그런데 QuestCodex 의 "아이템, 아이템, …" 목록은 조각마다 노드가 갈려 **통째로는 영영 안 맞는다.** 이제
**조각이 전부 사전에 있으면**(원문 유지 `null`·이미 한국어 포함 — `settled()`) 낱개로 바꾸고, 하나라도 빠지면 원문으로 둔다.
목록 줄이 영문으로 남아 있으면 그 줄의 이름 중 **하나라도 사전에 없다**는 뜻이다.

## 5. 이번에 틀렸고 사용자가 짚었다

- **카드만 하고 "한글화했다"고 보고했다.** 요청은 모드 페이지 **안쪽까지 전부**였다. 범위를 좁혀 놓고 끝났다고 했다.
  이 세션에서 가장 크게 지적받은 일이다 — 요청 범위 전체를 끝내기 전에는 끝났다고 하지 않는다.
- 나머지 실수(셸 heredoc 이 `\\` 를 `\` 로 먹어 정규식이 깨짐, rAF 가 앱 브라우저 창에서 안 돌아 번역기가 멈춤,
  SVG `<style>` 소문자라 CSS 를 번역함)는 점검 문서 A 절에 있다.

## 6. 알게 된 것

- **웹에 보이는 아이템 이름은 게임 locale 소관이다.** 웹 사전에 넣지 말고 `SptKoreanLocale` 에 넣는다 — 둘이 같은 말을 쓰게 된다.
- **서버·게임은 묻고 끈다.** 이번에도 사전을 다 만든 시점에 게임이 켜져 있어(PID 56876) 설치를 미뤘고, 사용자가 끈 뒤 재기동했다.
  웹 번역기 두 파일은 끄지 않고 넣을 수 있다.
- **고치면 숨어 있던 것이 드러난다.** 번역기 회귀를 고치자 합쳐진 문자열 속 아이템 이름 50개가 새로 보였다 — 수가 바로 줄지 않아도 실패가 아니다.
- **Git Bash heredoc 은 `\\` 를 먹는다.** 정규식이 든 파일은 Write/Edit 로 쓴다.
