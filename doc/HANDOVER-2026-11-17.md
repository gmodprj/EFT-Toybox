## 3. 화면으로 보고서야 드러난 것 — 로그가 거짓말을 했다

처음 판을 넣고 기동 로그는 "사전 항목 전부 사용됨"이었다. **게임을 켜 스크린숏을 찍으니** F12 의 Mod Settings·Show advanced·Undo,
F6 의 탭 이름(Home·Bot Settings…)이 영문이었다.

- **정적 생성자(`.cctor`) 글자는 IL 을 고쳐도 안 바뀐다.** Better BepInEx·SAIN 이 우리보다 먼저 올라와 이미 초기화돼 있다.
  SAIN "Bot Settings" 는 **이전 세션부터 사전에 있었지만 한 번도 한국어로 나온 적이 없다.**
  → 패치 뒤 그 타입의 정적 필드(문자열·배열·GUIContent·컬렉션 안 객체)를 다시 쓴다.
- **Harmony 가 다시 컴파일에 실패한 메서드(`MenuWindow::DrawRow`, IL Compile Error)의 항목도 "쓰임"으로 셌다.**
  → 패치가 끝까지 성공했거나 필드를 실제로 바꿨을 때만 센다. `DrawRow` 는 `excludeMethods` 로 뺐다(그 안의 초기화 버튼 등 3글자는 영문).

고친 판으로 다시 켠 뒤(사용자 허락) F12 창 틀·F6 탭이 **전부 한국어**인 것을 화면으로 봤다. 메모리에도 남겼다
(`static-ctor-strings-freeze-early`).

## 4. 범위를 일부러 좁힌 것

`node tools/check-dll-strings.mjs --where` 로 화면 글자와 같은 리터럴을 **열쇠로 쓰는 메서드**를 찾았다. 어셈블리 전체를 바꿨다면 깨졌을 것들:

| 모드 | 글자 | 다른 곳의 쓰임 | 조치 |
| --- | --- | --- | --- |
| Field Attachments | Ergonomics·Weight | 무기 비교의 리플렉션 속성 이름 | 비교 패널 메서드에서만 |
| Field Attachments | POSE FAULT | `StartsWith` 비교 | 넣지 않음 |
| Scope Rangefinder | OffsetX·Scale·Anchor | 프리셋 변환 JSON 열쇠 | 편집기 메서드에서만 |
| SAIN | Search·Name | 전투 레이어 이름·BigBrain 레이어 찾기 | 편집기 메서드에서만 |
| SAIN | Enter Name Here 등 | 그대로 새 프리셋 이름이 된다 | 넣지 않음 |

## 5. 이번에 틀렸던 것

- 점검 문서에 오역 셋을 적었다가 실측으로 거뒀다 — ImpactCue `Armor Hit Icon Color` 는 화면 영문이 "Penetrated Armor Icon Color" 라 "관통"이 맞았다.
  **열쇠 이름이 아니라 모드가 화면에 쓰는 영문으로 판단한다.**
- 낱말을 바꾸며 받침이 달라져 조사가 어긋났다("에너지을", "스태미나이"). 생성기·스크립트는 바꾼 낱말 뒤 조사를 받침에 맞춰 다시 쓴다.
- 점검 도구가 IL 을 콘솔 코드 페이지(cp949)로 받아 `—`·`✕` 가 `?` 로 깨져 "없음"으로 나왔다 — `chcp 65001` 로 받게 고쳤다.
- Better BepInEx 창은 자동 입력으로 잘 닫히지 않는다 — **창 밖(빈 배경)을 한 번 누른 뒤 F12** 로 닫힌다.

## 6. 도구

| 도구 | 쓰임 |
| --- | --- |
| `node tools/check-dll-strings.mjs [이름] [--list] [--where]` | `_dll-*.json` 을 게임 없이 IL 과 대조. `--list` 사전에 없는 영문 리터럴, `--where` 여러 메서드에 걸친 공통 항목 |
| `node tools/gen-impactcue-ko.mjs [--check]` | ImpactCue ko-KR 과 F12 ImpactCue 사전을 다시 만든다. 원본에서 시작해 멱등 |
| `pwsh -File tools/install-plugin-locales.ps1` | ImpactCue ko-KR 을 포함한 5개 locale 파일 설치. **모드를 업데이트하면 다시** |
| `pwsh -File tools/install-koreanconfig.ps1` | SptKoreanConfig DLL·사전 설치. DLL 은 게임이 꺼져 있어야 |

화면 확인은 computer-use 로 게임 창을 찍을 수 있다(앱 이름 `E:\Spt\EscapeFromTarkov.exe`).
