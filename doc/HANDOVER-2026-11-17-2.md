## 2. SptKoreanConfig 에 더한 것 — 리터럴이 아닌 글자 바꾸기

`lang/_dll-*.json` 에 셋을 더했다. 형식은 [src/SptKoreanConfig/README.md](../src/SptKoreanConfig/README.md) 끝.

- `resultMaps` — 함수가 **돌려주는 글자**를 사전으로(표 → F12 사전 이름 → F12 사전 설명).
- `argMaps` — 함수의 **첫 문자열 인자**를.
- `instanceFieldsOf` + `instanceStrings` — 이미 만들어진 플러그인 인스턴스의 문자열 필드를(탭 이름처럼 생성자에서 정해진 것).
- 그리는 함수에 걸리므로 **매 프레임 불린다**(실측: 메뉴를 몇 분 열어 두니 각 10만~20만 회). 할당 없이 사전 찾기만 하게 했고, 게임을 끌 때 호출 횟수를 로그에 남긴다.
- T Override 사전은 `node tools/gen-toverride-f12.mjs` → `node tools/gen-toverride-menu.mjs` 로 다시 만든다(모드를 업데이트하면 "빠짐"·"번역 없음"이 드러난다).

## 3. 좀비 모드 — 넣었다가 뺀 경위

- 선행 6개(Hideout Uncensored·Mapping SDK·Pack A Punch·Thundergun·Raygun·Perk Beverages)와 본체·Stronghold 맵을 하나씩 넣었다. 서버 190·플러그인 262 까지 갔다.
- **"보통 게임에서는 끄기"는 미리 넣은 `.cfg` 로 안 됐다** — 모드가 첫 기동에 `true` 로 되돌렸고, 첫 기동의 "YOUR NORMAL GAMEPLAY" 창이 정한다. 그리고 **프로필마다** 따로였다.
- 사용자가 매치를 해 보니 화면이 하얗게 덮였다. **FogSix** 가 좀비 맵 안개를 거의 최대로 그렸고(F12 에서 끄자 걷혔다), 걷힌 뒤에도 낮 9:30·구운 조명 0인 맵이라 표면이 날아갔다.
- 사용자 결정으로 8개를 뺐다. 폴더 16개·설정 7개·F12 사전 7개를 지우고 기록은 `install-records/removed/` 로, 매니페스트에는 `removed` 를 달았다(설치 목록에 "제거 — 사유"로 나온다).
  실행 중 생긴 파일은 `backup/stage14-E-removed-2026-11-17/`, 받은 압축·해제본(4.23GB)은 사용자 요청으로 지웠다.
- 다시 켜서 서버 183·플러그인 255·오류 기준선·프로필 11개 대조(남은 것 없음, Nomad 의 새 퀘스트 5개는 일일 퀘스트)를 확인했다.

## 4. 이번에 틀렸던 것·알게 된 것

- **"Fatal error — Another instance is already running" 창은 내 탓이었다.** computer-use `open_application("Escapefromtarkov")` 가 게임을 하나 더 띄웠다. 14-A 때는 원인을 몰라 "미확정"으로 적었다가 14-D 에서 대화상자를 찍어 알았다.
  게임 창은 PowerShell `(New-Object -ComObject WScript.Shell).AppActivate(<PID>)` 로 앞으로 가져온다(메모리 `open-application-spawns-second-eft`).
- **Better BepInEx F12 창은 사전을 고친 뒤 다시 열어도 반영되지 않는다** — 목록을 한 번만 만든다. 게임을 다시 켠다(MODS-GUIDE 고침).
- **자동 클릭이 안 먹는 UI** 가 있다 — Better BepInEx 의 열거형 드롭다운, 좀비 모드의 ZOMBIES MODE 버튼. 설정은 파일로 고쳤고(UI Fixes), 좀비 메뉴는 화면으로 못 봤다.
- 설치 생성기 `gen-installed-mods.mjs` 가 **새 차수를 모르면 목록에 안 싣는다**(단계 목록·제목에 14 를 더했다). 애드온은 매니페스트 `homepage` 로 링크.
- 설치 시험에서 생긴 파일이 **시험을 돌린 모드 몫으로 적혔다**(Satellite `config.jsonc` 가 Icebreaker 애드온 몫) — 본체 기록으로 옮겼다.
- 셸 따옴표 안에서 역슬래시가 먹혀 MODS-GUIDE 경로가 깨진 채 머지됐다(#116 → #117 로 고침). 경로가 든 글은 편집 도구나 파일로 쓴다.
- 받은 코드(JS)를 `require` 로 실행하려던 것은 막혔다 — 받은 파일은 글자로만 읽는다.

## 6. 다음 사람이 집을 거리

1. **Satellite 를 레이드 중에 본다** — 게임 안 `Left Alt+M`(처음엔 인증서 경고 "고급 → 계속"). Dynamic Maps 와 함께 켠 레이드 프레임도 본다. 지도 페이지 한국어(`ko.js`)는 맵 이름 6개가 영문이다.
2. **Hideout Last Stand 1.0.0** — 제작자가 곧 낸다고 했고 번역 JSON 폴더가 들어온다. 그때 업데이트하고 메뉴 알림·습격 화면을 한글화한다. 거치대 장비를 들고 싸우는 부분은 아직 시험되지 않았다.
3. **LootNet 을 업데이트하면** `LootNetFika.dll` 이 다시 들어와 T Override 가 꺼진다 — 다시 `.disabled` 로(MODS-GUIDE "알려진 충돌").
4. **Hideout Interiors 꾸미기 패널 글자**(DECORATE·분류·버튼)와 **T Override 이동 키 이름**(Flight Forward 등)은 영문이다.
5. `Hideout Uncensored` 의 `J` 와 Pinned Quest HUD 의 겹침은 좀비 모드와 함께 빠져 해당 없다. Hideout Last Stand 의 `Leave key = F10` 은 ImpactCue 와 겹친다(이긴 뒤 전용이라 둠).
6. 앞 인계의 거리는 [HANDOVER-2026-11-17.md](HANDOVER-2026-11-17.md) §7 에 그대로 있다(F8 두 편집기 레이드 화면, Better BepInEx 자기 설정 선택지 이름, ImpactCue 업데이트 때 재생성 등). 그중 2번(Hidden Caches)은 끝났다.
