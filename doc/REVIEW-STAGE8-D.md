## MagicBullet 3065

**내 쪽 총탄·근접 피해에만 배율을 건다.** 봇은 바닐라 그대로다.

- F12 슬라이더 둘: 총탄 피해 x1–x100, 근접 피해 x1–x100
- 원샷킬 체크박스 — 켜면 슬라이더는 무시되고 어떤 명중이든 즉사
- 배율은 **방어구 계산 뒤 남은 HP 에만** 적용된다. 권총으로 6급 방어구를 x100 으로 쳐도
  안 죽을 수 있다
- 수류탄·폭발·화염·낙하 피해는 그대로
- 내가 받는 피해, 봇끼리 주고받는 피해도 그대로

### 설치본과 겹치는 지점

**MeleeMultiplier 0.0.4 (8-A 에서 설치) 와 근접 피해가 곱해진다.**

현재 설정:

```json
{ "meleeDamageMultiplier": 10, "excludedMeleeItems": [ ... 2개 ] }
```

2763 은 **서버에서 근접 무기의 피해 수치 자체**를 x10 으로 올린다. 3065 는 **클라이언트에서
내가 주는 피해**에 배율을 건다. 층이 다르므로 덮어쓰지 않고 **곱해진다.**

즉 3065 의 근접 슬라이더를 x10 으로 두면 실질 **x100** 이 된다. 넣는다면 근접 슬라이더는
x1 로 두고 총탄 쪽만 쓰거나, 2763 의 배율을 먼저 낮추는 편이 맞다.

총탄 피해 쪽은 설치본에 겹치는 모드가 없다. `Headshot Damage Redirection 1.8.0` 은 헤드샷
피해의 **분배**를 바꾸는 것이라 배율과는 층이 다르다.

## Tushonka-800: Combat Augmentation System 3169

세 가지 시스템을 더한다. 성격이 꽤 다르다.

### Target Scanner

화면 중앙 16:9 틀 안의 적을 스캔해 **벽 너머 실루엣과 거리**를 표시한다.

- 시야가 트이면 최대 600 m, 벽·지형에 가리면 50 m 이내이고 스캔이 느려진다
- 식별 표시는 약 15초 유지

이건 사실상 **월핵에 가깝다.** 다른 둘(실드·오버드라이브)과 성격이 다르므로, 넣더라도
이 기능만 끌 수 있는지 먼저 확인하는 게 좋다.

설치된 **Amands' Sense 3.1.0** 과는 겹치지 않는다. 현재 설정을 보면 컨테이너·시체·루스
루트·탈출구를 반경 10 m / 지속 10초로 키 입력 시 비추는 **전리품 중심** 모드다. 살아 있는
적을 600 m 까지 벽 너머로 보는 것과는 다른 기능이다.

### Directional Force Shield

앞쪽에 삼면 육각 실드를 펼쳐 **들어오는 총알을 물리적으로 막는다.** 내구도가 있고 깨지면
쿨다운에 들어간다. 내 총알은 통과한다.

### Combat Overdrive

일시적으로 체력 재생·통증 억제·스태미나 증가·피해 감소·소지 한도 증가·스킬 레벨 상승을
한꺼번에 준다. 블랙아웃된 부위는 그대로다.

### 걸릴 만한 지점

화면에 요소를 직접 그리는 모드다. 설치본의 HUD 계열은 `Pinned Quest HUD 1.0.1`,
`Moe-TradeMarker 1.2.6` 뿐이고 표시 위치가 다르므로 큰 충돌은 예상되지 않는다. 다만
**8-G 로 검토 중인 GamePanelHUD 포팅본과는 화면을 같이 쓰게 된다** — 둘 다 넣을 생각이면
한쪽씩 넣고 확인하는 편이 안전하다.

## 정리

**기술적 위험은 낮다.** 둘 다 비결속·무의존성이고 클라이언트 쪽이라, 넣었다가 빼도 파일
삭제로 끝난다. 서버 모드 수도 늘지 않는다. 오늘 겪은 Miyako·PIT 같은 사고(프로필·스태시를
건드려 상태가 깨지는 종류)와는 성격이 다르다.

**판단은 취향 문제다.** Forge 가 치트로 표시한 이유가 분명하다 — 3065 는 피해 배율과
원샷킬, 3169 는 벽 너머 적 표시와 총알 차단이다. 난이도를 어디까지 낮출지는 정하실 몫이다.

넣는다면 이렇게 권한다.

1. **하나씩** 넣는다. 둘 다 F12 설정이 많아 섞으면 무엇이 무엇인지 가리기 어렵다
2. 3065 를 넣으면 **근접 슬라이더는 x1 로 둔다.** MeleeMultiplier 의 x10 과 곱해진다
3. 3169 는 Target Scanner 만 따로 끌 수 있는지 F12 에서 먼저 본다
4. 8-G HUD 포팅본과 3169 를 같이 넣지 않는다 — 한쪽씩 확인한다

## 확인하지 않은 것

- **둘 다 받지 않았다.** Forge 의 설명과 설치본 설정만 비교했다. 8-B 때처럼 DLL 을 열어
  보지 않았으므로, 실제로 어떤 후킹을 하는지는 확인하지 않았다
- ~~3169 의 F12 설정 항목이 실제로 무엇이 있는지는 모른다~~ → **확인했다. 아래 참조**
- 3065 의 근접 배율이 2763 과 곱해진다는 것은 두 모드가 건드리는 층이 다르다는 데서 나온
  판단이다. 실제 수치는 쏴 봐야 안다

## 설치 후 확정 (2026-10-27)

게임을 한 번 켜자 `BepInEx/config/com.rz99.combat-augmentation-system.cfg` 가 생겼다(18 KB,
항목 49개). 앞서 "추정"으로 남긴 것을 이걸로 확정한다.

**기능별 on/off 토글은 없다.** 섹션은 기능별로 나뉘어 있지만 전부 수치 설정이고, `Enable`
같은 켜고 끄는 항목이 Scan·Shield·Overdrive 어디에도 없다.

| 섹션 | 항목 수 |
| --- | --- |
| `4. Scan \| 扫描` | 20 |
| `6. Overdrive \| 超频` | 11 |
| `5. Shield \| 立场盾` | 8 |
| `3. Resources \| 资源` | 6 |
| `2. Wheel & Input \| 轮盘与输入` | 3 |
| `1. General \| 通用` | 1 |

참/거짓 항목은 다섯뿐이다 — `Debug Logging`, `Swallow CapsLock Toggle`, `Energy Cost`,
`Show Distance`(스캔), `Block Explosions`(실드).

**대신 기능은 레이드에서 스킬 휠로 골라 쓴다.** `Skill Key | 技能键 = V`, 길게 누르는 기준은
`Wheel Hold Threshold (ms) = 180`. 즉 끄는 설정이 없어도 **안 쓰면 그만**이다.

굳이 스캔을 무력화하려면 수치로 눌러야 한다.

- `Max Visible Distance (m) = 600` → 낮춘다
- `Max Occluded Distance (m) = 50` → 벽 너머 탐지 거리
- `Min Energy to Activate = 5`, `Energy Drain (per s) = 0.5` → 올린다
- `Off Cooldown (s) = 15`

기본값 중 눈에 띄는 것: 실드 `Durability = 2000`, `Armor Class = 2`, 오버드라이브
`Health Regen (per s) = 6`, `Damage Reduction (%) = 20`, `Stamina Capacity Bonus = 15`.
자원은 물·에너지를 쓴다(`Water Threshold = 10`, `Boost Water Drain (per s) = 2`).

언어는 영어·중국어 병기다. 한국어는 없다.
