# 2026-11-15 — 프로필 포터 격자의 겹침: 그리기가 아니라 **자료가 겹쳐 있다**

사용자가 **내보내는 쪽 격자에 항목이 겹쳐 보인다**고 알려 왔다(11-09 에 한 번 고친 자리다).

**이번에는 창이 틀린 것이 아니다. 프로필의 스태시 자료 자체가 겹쳐 있다.**

## 어떻게 가렸나

창이 쓰는 것과 **같은 라우트**를 셸에서 불러 자료를 그대로 받았다.

```
node tools/call-porter.mjs /profile-porter/stash '{"profileId":"6adc26693f5b5290609ea366"}'
```

Nomad 의 바닥 26개 가운데 **겹친 칸이 3개**다.

| 항목 | 자리 | 칸 |
| --- | --- | --- |
| `atlas_satchel` | (6,16) **세움** | 3×3 |
| WARTECH Warbelt Vector belt | (6,18) | 2×2 |
| Ferro Concepts Grenadier Belt | (8,18) | 2×2 |

3×3 이 (6,16) 에 있으면 **칸 6~8 · 줄 16~18** 을 덮으므로 18줄에서 두 벨트와 부딪친다.

### 크기는 서버가 말한 값이다

`atlas_satchel` 이 정말 3×3 인지 **서버에게 물었다**(`/client/items` 를 같은 왕복으로 받아 DB 를
그대로 읽었다).

```
661c917426ba940d7138e5cf  atlas_satchel  W3 H3
69364a368a4b47eeaf9ba4a3  WARTECH Warbelt Vector belt  W2 H2
6761b213607f9a6f79017afb  Ferro Concepts Grenadier Belt  W2 H2
```

**창도 서버도 이 값을 쓴다.** 즉 그린 그림이 자료와 어긋난 것이 아니라, 자료가 그렇게 생겼다.

## 혼자가 아니다 — 프로필 11개 중 6개

서버 DB 의 크기로 **모든 프로필의 스태시 바닥**을 훑었다(`r: Vertical` 이면 가로·세로를 바꾼다).

| 프로필 | 겹친 짝 |
| --- | --- |
| **Hawk** | **28** |
| Buck | 7 |
| Moose | 4 |
| Banshee | 3 |
| Nomad · Wraith | 2 씩 |
| 합계 | **46** |

겹치는 쪽은 거의 **큰 그릇**이다 — `item_equipment_tactical_rush100`(6×7 배낭) 하나가 Hawk 에서
10짝을 만들고, `atlas_satchel`·`item_equipment_backpack_wartech`·`item_equipment_rig_cs_assault`
가 그 뒤를 잇는다. 그 큰 사각형 안에 P90 부품·물물교환 재료 같은 1×1 들이 들어앉아 있다.

## 이번 작업 탓이 아니다

같은 잣대로 **백업 스냅샷**을 재 봤다.

| 스냅샷 | 겹친 짝 |
| --- | --- |
| `backup/profiles-before-update-2026-11-09/` | **42** |
| `backup/profiles-before-update-2026-11-15/` | 47 |
| `backup/profiles-before-stage12-2026-11-15/` | 46 |
| 지금 | 46 |

**11-09 에 이미 42짝이 있었다.** 이번 주의 업데이트 18개·STM 전송·체력 작업과는 무관하다.
(그보다 앞선 백업은 프로필이 1~2개뿐이라 견줄 수 없다.)

## 그럼 누가 그렇게 놓았나 — 아직 모른다

- 우리 **STM 스태시 전송은 자리를 검사한다** — `IsContainerSpotFree` 가 SPT 자신의
  `GetContainerMap` 으로 격자 지도를 만들고, 막혀 있으면 `TryPlaceFrom` 으로 빈 자리를 찾는다.
  `r: Vertical` 이면 가로·세로도 바꾼다. 겹쳐 놓을 길이 보이지 않는다.
- 스태시 바닥은 **격자가 하나**다(`slotId` 가 전부 `hideout`). "다른 격자라서 괜찮은 것" 이 아니다.
- 남는 후보는 **스태시에 물건을 바로 꽂는 바깥 도구**들이다 — `Give Ui.exe`, 상인 모드의 지급,
  부품을 풀어 놓는 모드 따위. **증명한 것은 없다.**
