## 5. 값을 치르고 배운 것

### 5-1. **md5 가 같아도 "최신" 이 아니다**

`PorterFiles.cs` 를 고치고 **재빌드 없이** 설치했다. 설치본과 빌드의 md5 는 일치했고 서버도
멀쩡히 떴지만 라우트 응답에 그 필드가 없었다 — **소스가 빌드보다 64초 새것**이었다.
둘이 사이좋게 옛것이었던 것이다.

> 설치 확인은 md5 한 줄로 끝내지 않는다. **설치본 시각 > 고친 소스의 시각**인지 함께 본다.

### 5-2. **통과만으로는 시험이 무엇을 지키는지 모른다**

P2 의 20건이 전부 녹색인 채로 `ImportPlanner` 의 검사 하나를 `if (false)` 로 들어냈는데
**20건이 그대로 통과했다.** 뒤따르는 다른 검사가 같은 꾸러미를 거절해 주었기 때문이다.
고친 것은 코드가 아니라 **시험**이다 — 어느 검사가 잡았는지를 **사유로** 확인하게 했다.

### 5-3. `Item.Location` 은 **`object`** 다

칸에 놓인 것은 `{x,y,r}`, 슬롯에 꽂힌 것은 정수 색인이라 SPT 가 한 타입으로 묶지 않았다.
**읽어 온 프로필은 `JsonElement`**, 서버가 만든 것은 `ItemLocation` 이다. `as ItemLocation`
만 쓰면 읽기 경로에서 조용히 null 이 되어 **110개가 전부 (0,0)** 에 겹친다.

회전은 **`r == "Vertical"`** 로 본다. 같은 자리의 `rotation` bool 과 **값이 다르다**
(실측 2 대 30).

### 5-4. `GetItemSize` 는 **컨테이너 내용물까지 더한다**

"이 트리를 격자에 **펼쳐 놓으면** 얼마나 필요한가" 를 재는 함수다. 같은 `Item Case` 가 안에
383개면 **38x4**, 77개면 11x5, 161개면 5x3 으로 나와 화면이 통째로 깨졌다. 스태시 표시에는
**tpl 기본 크기**(DB 의 Width/Height)를 쓴다.

### 5-5. 요청 본문의 **열쇠 이름이 대소문자를 가린다**

`[JsonPropertyName]` 이 없으면 PascalCase 로만 받는다. 창은 익명 객체를 보내 camelCase 가
나가므로, 서버가 조용히 null 로 받고 **"그 프로필을 찾지 못했습니다" 라는 엉뚱한 사유**로
거절한다. **사유가 그럴듯해서 더 나쁘다.**

### 5-6. 캔버스가 마우스를 붙잡으면 자식은 `Up` 을 못 받는다

끌어서 고르기를 넣으면서 `CaptureMouse` 를 했더니, 아이템 상자에 걸어 둔 클릭이 **영영 불리지
않았다.** 끌기와 클릭을 한 곳에서 처리한다 — 캔버스가 눌린 자리를 직접 찾는다.
