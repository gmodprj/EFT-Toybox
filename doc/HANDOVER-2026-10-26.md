### 3. WebConfigBridge — 서버 웹 모드 페이지

`src/WebConfigBridge` → `https://127.0.0.1:6969/webconfigbridge`

자체 편집 수단이 없는 서버 모드의 설정을 **탭 10개**로 고친다. `IModBlazorMetadata` + Razor 컴포넌트 방식이며 전례는 `JeroBackpack.ModMetadata`다.

탭: 무기·부품·탄약 호환 / **분류별 칸 열기** / 헬멧 부착 칸 / 지도 표식 / 보험 반환 / 플리마켓 / 수리 버프 / 거래 표시 / 사망 복원 / 무한 치트

주의할 점이 셋 있다.

- 저장은 즉시, **적용은 다음 서버 시작부터**. 대상 모드들이 설정을 시작 때 한 번만 읽는다.
- 저장이 `//` 줄 주석을 지운다. 처음 저장할 때 원본을 `.orig`로 남긴다.
- 모델에 없는 JSON 키는 `TargetConfig`(=`[JsonExtensionData]`)가 보존한다. 설치본의 실제 파일 8개로 왕복 시험을 붙였다(`src/CompatToggle.Tests/ConfigRoundTripTests.cs`, 38개 통과).

모드를 더하는 비용: POCO 하나 + 패널 하나 + `ConfigStore.RelativePaths`에 한 줄.

### 4. SlotCategoryRelax — 분류별로 골라 칸 열기

`src/SlotCategoryRelax`

`AllinWeaponUnslotted`는 칸 확장이 전부 아니면 전무라 "조준경은 열고 핸드가드는 닫는" 구분이 안 된다. 분류마다 켜고 끄는 모드를 만들었다.

- 규칙: 어떤 칸이 켠 분류의 부품을 하나라도 받고 있으면 그 칸에 같은 분류를 모두 넣는다. 넓히기만 하고 좁히지 않는다.
- 고를 수 있는 분류는 고정하지 않는다. 서버 시작 때 DB를 훑어 `discovered-categories.json`으로 내놓고(분류 이름 + 아이템 수), 모드 페이지가 그걸로 스위치를 만든다.
- 분류와 대상 칸 모두 `Mod` 계열로 제한한다. 그러지 않으면 보안 컨테이너·장비 칸까지 훑어 `Ammo`·`KeyMechanical` 같은 분류가 올라온다(57종 → 28종).

**현재 전부 꺼짐**이라 DB를 바꾸지 않는다.

## 남은 일

### A. 탄창 소실 오류 — 조치 대기 (우선)

레이드 중 재장전에서 탄창이 사라진다. **원인 확정됨**: `Mag Retention Reload` × `Direct Reload` 충돌의 재발. 2026-10-25에 정리한 그것과 예외 문구까지 같다.

```
[DirectReload] Direct reload failed: Direct load flow error |
System.Exception: Trying to get parent of an item that doesn't have a parent: ★ PMAG D60
```

`BepInEx/config/de.tosox.magretentionreload.cfg` 의 `Enabled`가 **true**로 돌아가 있다(그 파일 수정 시각 15:13, 게임은 15:00 시작 — 세션 중 F12에서 건드려졌다).

조치: 그 항목을 끈다. 게임이 켜져 있으면 F12에서, 꺼져 있으면 파일에서. 파일로 고칠 때는 **게임이 꺼져 있어야 한다** — 켜져 있으면 종료 시 메모리 값으로 덮어쓴다. 탄창 회수 기능은 UI Fixes가 맡으므로 잃는 것은 없다(`Reload Magazines In-Place = true` 확인됨).

자세한 기전은 `doc/MODS-GUIDE.md`의 "알려진 충돌"에 있다. 재발했으므로 그 문서에 "켜지 말 것" 경고를 더 분명히 적는 것이 남은 일이다.

### B. 모드 페이지 탭 확인

탭 10개 중 첫 탭 바깥은 서버 응답에 들어오지 않는다(MudTabs가 활성 패널만 그린다). 아래는 사람이 열어봐야 확인된다.

- 숫자 입력칸(보험 반환 7개, 수리 버프 3개)이 제대로 뜨는지
- "무한 치트" 탭의 프로필별 반복 렌더
- "분류별 칸 열기" 탭의 분류 28개 스위치

### C. SlotCategoryRelax 분류 고르기

사용자가 페이지에서 직접 고르기로 함. 고른 뒤 서버 재시작이 필요하고, 로그에 "분류 28종 중 N종을 켰다(…). 칸 N개에 항목 N개를 더했다"가 찍히므로 숫자로 확인할 수 있다.

### D. 알려진 결함 — 모드 페이지의 묵은 값 저장

패널은 열릴 때 파일을 읽고, 저장할 때 **들고 있던 값을 그대로 쓴다.** 페이지를 열어둔 사이 파일이 밖에서 바뀌면(다른 도구·직접 편집) 저장이 그 변경을 되돌린다.

실제로 겪었다 — `FckWeapons`를 파일에서 false로 바꿨는데 나중에 true로 돌아가 있었다. 저장 전에 다시 읽어 비교하거나, 최소한 파일이 바뀌었으면 경고하는 처리가 필요하다.

### E. 보류한 미나드 (CompatToggle 전역 리뷰에서)

CompatToggle은 철회했으나 리뷰가 남긴 지적 중 일반적인 것:

- `Enable()` 을 개별 try/catch 없이 연달아 호출하면 게임 업데이트 때 일부만 걸린 채 끊긴다
- 설치 스크립트가 서버 실행 여부를 보지 않는다
