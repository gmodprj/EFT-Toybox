**모드가 설정 파일을 함께 싣는다.** 그걸 덮으면 쓰던 값이 기본값으로 돌아간다. 이번에 둘이
걸렸다.

| 모드 | 날아갈 뻔한 것 |
| --- | --- |
| Realistic Insurance 0.2.3 | 보험 확률 6개(PMC 65% · 약탈자 탈출 25% 등) |

**둘 다 `install-and-test.ps1` 의 덮어쓰기 검사가 멈춰 세워 알게 됐다.** 그 안전장치를 끄거나
`-Force` 같은 것을 만들면 이런 것이 조용히 지나간다 — **끄지 말 것.**

**모드 폴더 안의 번역도 날아간다.** ISB 자막 `kr.json` 은 설치 기록에 없어 살아남았지만, 그건
운이 아니라 기록에 없기 때문이다. 업데이트 뒤에는 `tools/install-plugin-locales.ps1` 을 다시
돌리고 `node tools/check-plugin-locales.mjs` 로 센다.

## 5. 값을 치르고 배운 것

- **`Select-Object -First` 는 위쪽 명령을 끝낸다.** 그래서 ISB Aishi 는 설치만 되고 서버 테스트가
  잘렸다. 뒤로는 `-Last` 를 쓴다.
- **오류 문구만으로 판정하지 않는다.** bsdtar 가 `empty or unreadable filename … skipping` 으로
  오류 종료했지만 압축 안 파일 3,880개 = 해제된 파일 3,880개였다. 이름이 빈 항목 하나를 건너뛴 것이다.
- **호스트마다 받는 길을 재고 고른다.** github.com 리다이렉트가 여섯 번 504(→ `gh release
  download`), Cloudflare Worker 는 한 줄기 1.6KB/s(→ Range 열여섯 줄기, 그래도 느려 **다음 날로
  미루니 8.3MB/s**), pixeldrain 은 한 줄기 23MB/s(끊어 받는 쪽이 오히려 느리다).
- **느린 다운로드는 마지막까지 미룬다**(사용자 결정). 하나가 줄을 막으면 할 수 있는 일이 다 멈춘다.
- **생성기는 적용된 상태를 기준으로 삼으면 안 된다.** ISB 생성기가 이미 입혀진 한국어를 기준으로
  삼아 두 번째 실행에서 **사전을 비웠다**(374항목). 영문만 보고 고르도록 고쳐 멱등해졌다.
- **책임 범위는 맡은 열쇠만 적는다.** `id×(Name|ShortName)` 으로 넓게 적어 번역하지 않은 짝 92개가
  "묶음에서 빠뜨림" 으로 잡혔다.

## 6. 설치본을 통째로 떠서 올렸다 — 46 GB

자세한 것은 [EXPORT-2026-11-10.md](EXPORT-2026-11-10.md), 도구는 [tools/export/](../tools/export) 넷.

- 떠낸 것 **16,622개 / 46,016.7 MB**(빠진 항목 0) + 문서 323개. 앞 회차(2026-10-26)의 3,411개 /
  7,985 MB 에서 **5.8배**가 됐다 — 10차와 업데이트로 들어온 대형 콘텐츠 모드 때문이다.
- `SPT-Mods-2026-11-10.zip` 42.4 GB(94.3%, 13.4분) · `SPT-Profiles-2026-11-10.zip` 30.8 MB.
  둘 다 `gdrive:SPT-Mods/2026-11-10/`. 스테이징은 `E:\Spt_Mods_Export\SPT-Mods-2026-11-10\`.
- **담는 기준을 두 길로 합쳤다** — 폴더 전체(`plugins`·`config`·`patchers`·`user\mods`·
  `user\patchers`) + 설치 기록 중 그 폴더 밖 22개 + 기록에 없는 루트 모드 파일 6개. 한쪽만으로는
  설치 후 생긴 설정이나 루트 실행 파일을 놓친다.
- **서버·게임이 떠 있는 채로 떴다**(끄지 않았다). 프로필 191개를 복사한 뒤 전부
  `JsonDocument.Parse` 로 열어 보고, 깨지면 다시 뜨고 세 번 다 깨지면 멈추게 했다 — 1차 통과.
  zip 둘은 다시 열어 항목 수·합계를 견주고 표본 20개를 풀어 CRC 를 봤다. **남는 한계: 게임 종료
  때 저장되는 F12 값은 이 스냅샷에 없을 수 있다.**
- **rclone 설정이 사용자 셸에는 없다.** 터미널 탭에서 돌린 업로드가 `didn't find section in
  config file ("gdrive")` 로 죽었고, 그 셸의 `Test-Path` 는 False 인데 에이전트 도구 쪽에는 있다.
  `--config` 로 박아도 안 된다 — **업로드는 에이전트 도구 환경에서 돌린다.**
- **rclone 진행률의 분모는 두 배로 뜬다**(42.4 GiB 인데 `/ 84.738 GiB, 51%`). 전송 뒤 검증 패스의
  표기다. 51% 를 "절반" 으로 읽으면 안 된다.

## 7. 저장소를 GitHub 에 올렸다 — 이제 PR 로 간다

이 저장소에는 **`origin` 이 없었다.** 원격은 `pit-upstream`(PIT Fireteam 업스트림)뿐이어서, 지금까지
"작업 브랜치 → develop → main" 흐름을 **전부 로컬 머지 커밋**으로만 했다(main 의 `Release ...`
커밋들이 그것이다).

- `origin` = [gmodprj/EFT-Toybox](https://github.com/gmodprj/EFT-Toybox). 올리기 전 **빈 PUBLIC
  저장소**였다.
- 공개 저장소라 올리기 전에 추적 파일 2,231개를 훑었다 — 이메일·토큰·`C:\Users` 경로 **0건**.
  디컴파일된 게임 코드도 커밋돼 있지 않다(`// Token: 0x` 를 쓰는 파일 2개는 런타임에 밖에 있는
  파일을 **파싱만** 한다). `downloads/`·`extracted/`·`backup/` 은 `.gitignore` 로 빠진다.
- **라이선스는 MIT 로 걸었다**(사용자 결정). 다만 **업스트림 PIT Fireteam 에는 라이선스 파일이
  없다** — GitHub API 404, 루트에도 없다(2026-11-10 확인). 라이선스 없는 공개 코드는 모든 권리가
  저작자에게 있으므로, **포크분(`src/SptTeamManager*`, 추적 파일 895개 = `src/` 의 69%)까지 MIT 로
  덮으면 사실과 다른 주장**이 된다. 그래서 `LICENSE` 는 순수 MIT 문구만 두고(GitHub 이 MIT 로
  인식하게), 범위 밖은 [`NOTICE`](../NOTICE) 와 README 의 "라이선스" 절에 적었다 — 포크분, Forge
  에서 옮겨 적은 모드 메타데이터, BSG·SPT 와 무관함 셋이다. 저작권자 이름은 커밋에 쓰는
  `Qahnaarin` 으로 적었다.
- 이제 원격이 있으므로 **다음 변경부터는 작업 브랜치 → develop PR → (릴리스 때) develop → main
  PR** 로 간다. 로컬 머지만으로 끝내지 않는다.
