## 3. 이번에 알게 된 것

- **SPT 시즌 이벤트를 고치는 서버 모드는 199999 앞에서 돌아야 한다.** `GameCallbacks`(200000) → `PostDbLoadService.PerformPostDbLoadActions` → `EnableSeasonalEvents` 가 그때 한 번 읽는다. 다른 자체 모드처럼 `PostLoad` 에 두면 효과가 없다. PPES `SeasonalApplier` 는 199999.
- **서버 웹 번역 사전 `ko-ui.json` 은 재시작 없이 바로 먹는다** — ModCardKorean 이 요청마다 파일을 읽는다. 설치 스크립트는 서버가 떠 있으면 거절하므로, 사전만 바꿀 때는 설치본과 HEAD 가 같은지 본 뒤 그 파일 하나를 복사했다. 모드 카드(`mod-cards.ko.json`)·게임 locale 은 재시작이 필요하다.
- `tools/stop-spt-server.ps1` 은 **런처도 닫는다** — 사용자에게 알린다.
- 번역을 덩이로 나누면 같은 이름이 덩이마다 갈린다(보스 집결/보스들의 집결, 테라그룹의 흔적/자취). 합칠 때 **게임 화면 기준 이름표**(저장소 `quest-names-*.json` → 우리 퀘스트 이름 번역)로 맞추고 문장 속 인용까지 대조했다. 연작 표기 관례는 "- 파트 N"(366건).
- 셸 인자 안 정규식·경로의 역슬래시가 두 번 먹혔다(규칙 `(\d+)` → `(d+)`, 경로 `\\`). 정규식·경로가 든 것은 파일로 쓴다.
- check-locale-dict 의 "빠뜨림 28" 은 PPES 퀘스트가 아니라 **바닐라 kr 에 영문으로 있던 이벤트 퀘스트 이름**이었다 — PPES 가 그 퀘스트들을 꺼내면서 드러났다.
- PPES 설정은 웹 페이지에서 저장되면 파일이 바뀐다. 파일 시각과 내 도구의 실행 시각을 견줘 **사용자 변경인지** 가리고 되돌리지 않았다.
