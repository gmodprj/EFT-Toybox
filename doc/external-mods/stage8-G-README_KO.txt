GamePanelHUD SPT 4.1.6 포팅본

설치:
1. SPT 서버와 게임을 완전히 종료합니다.
2. 이 압축 파일의 BepInEx 폴더를 SPT_Runtime 폴더에 드래그하여 덮어씁니다.
3. 기존 kmyuhkyuk-KmyTarkovApi 폴더가 있다면 반드시 덮어써서, 예전 Kmy Tarkov API DLL과 섞이지 않게 합니다.
4. 게임을 한 번 실행합니다.

포함:
- GamePanelHUD 4.1 포트 소스에서 빌드한 HUD DLL 7개
- 해당 HUD가 요구하는 Kmy Tarkov API 2.0.0 DLL 3개
- 원본 HUD 번들 및 언어 파일

주의:
- SPT 4.1.6의 클라이언트 Managed/Core DLL을 참조해 컴파일했습니다.
- 레이드에서 각 HUD 기능의 실제 동작은 게임 실행으로 최종 확인해야 합니다.
