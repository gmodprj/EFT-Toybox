# GogglesWheel — 야시경·실드 휠

N 하나로 야시경과 페이스실드를 갈라 여닫는다. **짧게 누르면 야시경**, **길게 누르면 원형 메뉴**가 뜨고 마우스를 기울여 고른 뒤 N을 떼면 그것이 여닫힌다.

## 왜 필요한가

헤드기어 장착 제한을 푸는 모드를 넣으면 헬멧에 야시경과 페이스실드를 동시에 달 수 있다. 그런데 게임의 `Player.ToggleGoggles` 는 이렇게 생겼다.

```csharp
TogglableComponent c = helmet.GetItemComponentsInChildren<TogglableComponent>().FirstOrDefault();
```

**첫 번째 하나만** 건드린다. 바닐라에서는 둘이 동시에 달릴 수 없어 드러나지 않던 구멍이고, 제한을 푸는 순간 한쪽을 영영 못 열게 된다.

설계는 [doc/specs/2026-10-30-goggles-wheel-design.md](../../doc/specs/2026-10-30-goggles-wheel-design.md).

## 어떻게 동작하나

| 입력 | 하는 일 |
| --- | --- |
| 짧게 N | 기본 대상(야시경)을 여닫는다. 토글은 키를 **뗄 때** 일어난다 |
| 길게 N (기본 0.25초) | 휠이 뜬다. 마우스를 기울여 고르고 N을 떼면 적용. 가운데에 둔 채 떼면 아무 일도 없다 |
| 여닫이가 하나뿐인 헬멧 | 휠 없이 즉시 여닫는다 — 고를 것이 없는데 기다리게 하지 않는다 |

휠 항목은 헬멧에 실제로 달린 여닫이에서 자동으로 만든다: 야시경 → 열화상 → 페이스실드 → (힌지 헬멧이면) 바이저 자신 → 그 밖. 헬멧의 전술 라이트는 게임이 헤드라이트 키로 따로 다루므로 건드리지 않는다.

## 남의 모드와 부딪히지 않게

같은 메서드를 이미 가로채는 모드가 둘 있다. 다음 두 경우에는 **우리가 물러난다**.

- **COTI 수정키가 눌린 N** — COTI 가 먼저 쓰던 입력이다. (`standDownForCoti`)
- **우리 차례에 N 이 눌려 있지 않을 때** — 사람이 아니라 코드가 부른 것이다. UI Fixes 가 왼손 나침반을 치운 뒤 되부르는 자리가 여기다. 이때 휠을 띄우면 떼어질 일 없는 키를 기다리며 입력이 잠긴다. 그래서 휠 없이 기본 대상만 즉시 여닫는다.

## 시점은 막고 이동은 남긴다

휠이 떠 있는 동안 시점(Look)과 회전(Turn) 축만 0 으로 누른다. 이동과 린은 그대로다. 바닐라 제스처 휠은 축을 통째로 꺼서 이동까지 멈추는데, 이건 교전 중에 쓰는 동작이라 제자리에 얼어붙으면 안 된다.

방향은 그 막는 자리에서 받은 시점 입력을 그대로 쓴다 — 마우스 감도·반전 설정이 그대로 반영된다.

## config.jsonc

플러그인 폴더에 있다. 설치 스크립트는 **이미 있는 설정을 덮어쓰지 않는다.**

| 항목 | 기본값 | 뜻 |
| --- | --- | --- |
| `enabled` | true | false 면 패치를 걸지 않는다(N 이 게임이 하던 대로) |
| `longPressSeconds` | 0.25 | 길게로 치는 기준. 0.05~2.0 밖은 눌러 쓴다 |
| `defaultTarget` | `nightvision` | 짧게 눌렀을 때 — `nightvision`·`faceshield`·`first` |
| `wheelDeadZone` | 0.2 | 이 아래로 기울이면 고르지 않음 |
| `useGameWheelSkin` | true | 제스처 휠 항목 템플릿을 복제해 쓸지 |
| `includeHelmetVisor` | true | 힌지 헬멧 자신을 항목에 넣을지 |
| `standDownForCoti` | true | COTI 수정키가 눌린 N 을 넘길지 |

F12 에는 켜기/끄기 하나만 둔다.

## 안 되는 경우

- `Player.ToggleGoggles` 를 못 찾으면 **아무 것도 걸지 않고** 로그 한 줄만 남긴다. N 은 게임이 하던 대로 돈다.
- 시점 축을 막을 자리를 못 찾으면 그것만 포기한다 — 휠은 뜨고 시점이 도는 것으로 끝난다.
- 제스처 휠 템플릿을 못 찾으면 단순한 항목으로 그린다.
- N 키 조합을 못 찾으면 길게 누르기를 쓸 수 없어 기본 대상만 여닫는다.
- 레이드 밖에서는 아무 것도 하지 않는다.

## 빌드·설치

```
dotnet build src/GogglesWheel -c Release
pwsh -File tools/install-goggleswheel.ps1
```

제거는 `-Remove`. 게임만 다시 켜면 되고 서버는 끌 필요 없다.

판정 로직(설정·각도·기본 대상·분기 판단)은 게임 어셈블리를 모르는 파일로 떼어 두어 EFT 없이 시험한다: `dotnet test src/GogglesWheel.Tests`.
